# Gradivo za 3.0 Elektronski regulacijski sistemi

`300_Regulacijska_zanka.png` je prikaz blokovne sheme iz lokalnega gradiva
[Slavko Kocijančič: Projekti iz elektronike](../../Proj-eltron_2020.pdf#page=32),
tiskana stran 29 (32. stran datoteke PDF).

Slika je neposredno izrisana iz dela izvorne strani pri 300 dpi. Oznake in
povezave niso spremenjene. Bloki N, PR, R, S in M so pojasnjeni v poglavju 3.0.
Izvirnik na naslovnici navaja leti 2011 in 2020 ter interno uporabo na UL PeF.
